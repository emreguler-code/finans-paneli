# Güncel geliştirme başlangıcı

Önce kökteki AGENTS.md, README.md ve [tek tasarım sözleşmesini](TASARIM-SOZLESMESI.md) okuyun. Sürüm tarihçesini geçerli tasarım talimatı olarak kullanmayın. Açık kodlama talimatı olmadan uygulama değiştirilmez; talepler SONRAKI-SURUM-NOTLARI.md içinde tutulur.

Node/npm/Python sürüm dosyalarını kullanın; npm ci ve npm test çalıştırın. Görsel değişiklikte çalışan derlemenin geniş/dar ve mobil durumlarını inceleyin. Güncel tarayıcı testleri package.json içindedir. Yalnız taşmama kabul için yeterli değildir.

Yerel API için README'deki izole Docker test koşucusunu kullanın; gerçek hosting config/veri/şifre kullanmayın. Şema ve finansal sınırlar AGENTS.md ve ilgili sürüm kapsamındadır. Hosting yükleme/inceleme kullanıcıya aittir.

Eski devir notu [tarihçede](tarihce/CODEX-BASLANGIC-1.29.md) korunur.
