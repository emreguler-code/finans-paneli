# Tarihsel API testleri

Bu betikler eski API sözleşmelerini ve sürüm beklentilerini belgeler; güncel sürüm kabul testleri değildir. Üretim veya geliştirme veritabanında çalıştırmayın. Güncel test komutları `npm run test:api`, `npm run test:migrations` ve `npm run test:browser` komutlarıdır. Eski dosyalar Git geçmişi ve test niyetini korumak için burada tutulur.
